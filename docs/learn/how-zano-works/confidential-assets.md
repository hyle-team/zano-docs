# Confidential Assets

Confidential Assets let anyone issue their own tokens on the Zano chain. Issued assets get the same privacy as native ZANO: hidden addresses, hidden amounts, and a hidden asset type, with the same public verifiability that no transaction creates or destroys coins.

That means you can launch a private stablecoin, a shielded version of an existing asset, or any other token without running a separate blockchain. Live examples include [fUSD (Freedom Dollar)](https://www.freedomdollar.com), a private stablecoin, and the wrapped assets bridged through [Confidential Layer](https://confidentiallayer.com).

For the full scheme, see "Zano: Confidential Assets Scheme for RingCT and Zarcanum" in the [research papers](/docs/learn/research). Developers can find asset-related APIs in the [Build section](/docs/build/overview).
