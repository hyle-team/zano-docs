# Codebase Overview

This section documents the internals of the Zano C++ codebase, written for anyone reading the source or contributing to the core. If you want to integrate Zano into an app, service, or exchange instead, the [Build section](/docs/build/overview) has the APIs and guides for that.

Current articles:

- [Serialization types](internals/serialization-types.md): the three serialization mechanisms used to store C++ objects, what each guarantees, and where you'll meet them in the source.

The [codebase itself](https://github.com/hyle-team/zano) is on GitHub, and reproducible build instructions are in [Building from sources](/docs/build/building-from-sources).
